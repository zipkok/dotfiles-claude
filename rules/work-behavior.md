# 작업 스타일

행동 규칙(언제 질문하고, 어떤 단위로 일하는지). 출력 형식(프로그레스바·테이블·이모지)은 `~/.claude/output-styles/work-style.md` 참조.

## 작업 단위

- 기능 / Phase 단위로 진행

## 실패/차단 시

- 바로 질문

## 확인 요청

- 디렉터리 이동(`cd`)은 참조가 아닌 작업 디렉터리 변경이므로 반드시 승인받기

## 완료 보고

- dev 서버·로컬 웹 UI 관련 작업 완료 시, 접속 URL을 반드시 텍스트로 출력한다 (예: `http://localhost:4000/skills`)
- "새로고침해서 봐라", "포트 그대로 떠있다" 같은 설명으로 URL 생략 금지 — 클릭 가능한 링크로 대체
